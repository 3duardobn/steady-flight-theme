# 0rwx Standard Declaration — Steady Flight Theme

[![0rwx: x](https://img.shields.io/badge/0rwx-x%20%7C%20execute-critical?style=flat-square)](https://0rwx.com)

This repository adopts the **[0rwx Framework](https://0rwx.com/)** to provide clear transparency on the level of Artificial Intelligence involvement in its source code, architecture, and maintenance.

---

## Project Classification: **Level x (Execute / "I curate")**

According to the [0rwx](https://0rwx.com/) taxonomy:

| Level | Unix Label | Philosophy | Application in this Project |
| :---: | :---: | :--- | :--- |
| **0** | *Zero* | *"I think"* | 100% manual code, no AI models involved. |
| **r** | *Read* | *"I make"* | AI acts purely as an advisor/documentation reader. |
| **w** | *Write* | *"I fix"* | AI writes portions of code with line-by-line human inspection. |
| **x** | **Execute** | **"I curate"** | **Agentic vibe-coding workflow, with human curation and behavioral validation.** |

---

## How development works in practice

1. **Agentic Generation**: Technical implementation, styling, and scripts are developed primarily using agentic AI models (Claude, Gemini, Antigravity, OpenCode).
2. **Human Direction & Curation**: The human maintainer directs scope, architecture, visual aesthetics, and acceptance criteria.
3. **Behavioral Validation**: All generated code is tested, inspected, and validated in real environments to ensure reliability and visual/functional fidelity.
4. **Warranty Disclaimer**: Software is provided "AS-IS", under the terms of the repository license.

## Contributions and Pull Requests

If you wish to submit contributions:
- Manual contributions (levels `0` or `r`) and AI-collaborated contributions (`w` or `x`) are welcome.
- When opening a Pull Request, please declare the corresponding 0rwx level (e.g., `0rwx: w` or `0rwx: x`) in the description to maintain transparency.
